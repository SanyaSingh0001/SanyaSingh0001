🚀 Featured Projects

🏛️ "HistorIA — The Ancient Archive" (https://history-ai-phi.vercel.app/)

A RAG-powered historical research assistant

A scholarly AI application designed to answer historical questions using a curated library of 30 history volumes and 2,796 text chunks.

- Retrieval-Augmented Generation (RAG) with semantic search
- Google Gemini models and ChromaDB vector storage
- FastAPI backend with Redis-based session memory and rate limiting
- Source-aware answers, historical timelines, voice interaction, and study exports

Tech: Python, FastAPI, React, ChromaDB, Redis, Gemini, RAG

- AI-assisted issue categorization and severity assessment
- Firebase Authentication and Firestore integration
- Interactive maps, community verification, and issue tracking

Tech: Next.js, TypeScript, Firebase, Google Gemini, Google Maps
